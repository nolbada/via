because, if, that

  1. STEP 1알맞은 말 고르기
  2. STEP 2보기 문장 고르기
  3. STEP 3접속사 고르기
  4. STEP 4영작
POINT 1

because · if · that

because~하기 때문에 (이유)
if만약 ~하다면 (조건)
that~라는 것 (명사절)

because와 if는 부사절, that은 명사절을 이끕니다.

POINT 2

if절의 시제

if절미래라도 현재시제
주절will 사용

We’ll be happy if we win the game tonight.(우리가 오늘 밤 경기에서 이기면 행복할 것이다.)

POINT 3

that절의 역할

주어~하는 것은 (It ~ that)
목적어~하는 것을 (that 생략 가능)
보어~하는 것(이다)

It is true that Andy is a good student.(Andy가 좋은 학생이라는 것은 사실이다.)

POINT 4

that절을 목적어로 쓰는 동사

think · know · believe생각하다 · 알다 · 믿다
hope · tell · say바라다 · 말하다 · 말하다

I think (that) Andrew is funny.(나는 Andrew가 재미있다고 생각한다.)

STEP 1

( ) 안에서 알맞은 말을 고르시오

  • ① 빈칸 앞뒤를 보고 이유 · 조건 · 내용 중 어떤 관계인지 정한다.
  • ② 이유는 because, 조건은 if, 내용(주어 · 목적어 · 보어)은 that을 고른다. if절 안의 동사는 현재형인지 확인한다.
STEP 1 · 1번

The truth is (that / because) we are late.

단어 뜻
  • the(그)
  • truth(진실)
  • is(be동사, 주어 the truth에 맞는 현재형, ‘~이다’)
  • that(~라는 것)
  • because(~하기 때문에)
  • we(우리는)
  • are(~이다)
  • late(늦은)
생각해 보기
  • is 뒤에서 ‘진실은 ~이다’의 빈 곳을 채우는 말이 필요합니다. 보어 자리에는 어떤 절이 오나요?
  • 본책 p.152 C의 보어 역할 표를 확인하세요.

STEP 4

우리말과 일치하도록 ( ) 안의 말을 이용하여 문장을 완성하시오

  • ① 우리말에서 이유(~때문에) · 조건(~하면) · 내용(~라는 것)을 찾는다.
  • ② 접속사를 정하고 ‘주어 + 동사’를 이어 쓴다. if절은 현재시제, 가주어 It 문장은 It ~ that 순서로 쓴다.
