당하는 주인
The problems
any weaknesses
need to + be p.p.
need to be solved
need to be addressed
쉬운 예 해석 · 그 문제들은 해결되어야 해요(problem 문제, solve 해결하다).
이번 문장 해석 · 해결되어야 한다
틀린 예The problems need to solve.
(문제는 스스로 푸는 게 아니라 풀리는 쪽이라서 to solve가 아니라 to be solved예요)
to + 동사원형 가 맞는 예We need to solve the problems.
우리는 그 문제들을 풀어야 해요(we는 직접 푸는 쪽이라서 to solve가 맞아요).

왜 그럴까요

약점은 누군가가 '해결해 주는' 대상이에요. 약점이 스스로 해결할 수는 없어요. 그래서 need to address(해결하다)가 아니라 need to be addressed(해결되다)예요. weaknesses가 여러 개라서 need에 -s가 없어요.
출제 순위 · 상위 10위 밖 유형이에요.
주어가 행동을 당하면 to 뒤에 be p.p.가 와요
