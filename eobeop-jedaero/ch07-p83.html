호기심은 종종 우리가 어려운 문제를 흥미로운 도전으로 보게 만든다, 그리고 만약 우리가 이런 방식으로 실패에 접근한다면, 우리는 훨씬 더 빨리 배울 것이다.

한 줄 정리

호기심이 있으면 어려운 문제도 재미있는 도전으로 보여서, 실패도 그렇게 보면 더 빨리 배운다는 얘기예요.
오답노트에는 이것만
If+주어+과거동사, 주어+would+동사원형
쉬운 예이번 문장
if 절
if I had wings
if we approached failure
주절
I would fly
we would learn
쉬운 예 해석 · 내게 날개가 있다면 나는 날 텐데요(wing 날개, fly 날다).
이번 문장 해석 · 만약 우리가 실패를 이렇게 대한다면, 우리는 배울 텐데
틀린 예If I had wings, I will fly.
(if절이 had(가지고 있다, 과거형)로 지금 사실과 반대라서 주절은 will이 아니라 would(~할 텐데)예요)
will 가 맞는 예If it rains, I will stay home.
비가 오면 나는 집에 있을 거예요(실제로 일어날 수 있는 일이라 if절은 현재형, 주절은 will).

왜 그럴까요

if 절에 approached(approach(대하다)의 과거형)가 있지만 '옛날 일'이 아니에요. 지금 사실과 다르게 가정하는 '가정법 과거'라서 과거형을 썼어요. 이럴 때 주절은 will이 아니라 would + 동사원형(learn 배우다)이에요.
출제 순위 · 상위 10위 밖 유형이에요.
if절이 과거형이면 주절은 would + 동사원형이에요
