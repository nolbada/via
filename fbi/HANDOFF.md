# FBI 앱 인수인계 (Claude용)

새 대화에서 "FBI 학생용 / 수업용 검수·수정"을 요청받으면 이 문서를 먼저 읽고 시작할 것. 사용자: Julia 선생님(비타민 영어클리닉). 비밀번호·개인정보는 이 문서에 넣지 않는다(공개 저장소).

## 1. 앱 구조 (저장소 nolbada/via, 브랜치 main)
- fbi/g1-9 : 고1 9월 학생용 앱 (OMR 입력, 해설, 단어 등)
- fbi/g1-9-class : 고1 9월 교사용(수업용) 앱. index.html이 표지 + 24개 지문 링크 허브, 지문별 g1_YY_9_NN.html
- fbi/g2-6 : 고2 6월 학생용(문장 분석 등)
- fbi/g2-6-class : 고2 6월 교사용(수업 노트). 23·24·25년 6월 x 31·32·33·34·36·37·38·39번
- links/fbi/index.html : "FBI 교사용" 링크 모음 페이지(태블릿 홈 화면에 추가해서 사용). 고1 9월 / 고2 6월 두 항목, 왼쪽 띠를 각 책 표지 색으로 구분
- links/index.html : "앱 링크" 모음(V SIGNAL K/E/Y, X-RAY, FBI 학생용, 비단챌, VOCA LINK). 동료 선생님 전달용
- 주소 형식: https://nolbada.github.io/via/<경로>/

## 2. 표지 색 (실제 책 표지 기준)
- 고1 기본 SEPTEMBER: 배경 #133040, 코랄 #F79786, 크림 #E8DFD5, 외곽선 FBI 글자
- 고2 심화 JUNE: 배경 #6e1c47(자주), 민트 #94dabd
- 앱 표지에 학원 이름은 넣지 않는다.

## 3. GitHub 수정 절차 (브라우저로 직접)
- 요청받은 파일만 수정한다. 다른 파일은 절대 건드리지 않는다(과거에 다른 파일을 잘못 건드려 수업 중 문제가 난 적 있음).
- 수정 전: /edit/main/<경로> 에서 현재 내용의 해시(끝 개행 제거 후 SHA-256 앞 12자리)가 로컬 기준본과 같은지 확인. 다르면 현재 것에 변경만 얹는다.
- 편집기: .cm-content 의 cmView.view.dispatch 로 내용 교체, 커밋 후 github 쪽 raw 해시와 nolbada.github.io 에서 fetch(cache:'reload') 해시로 확인(Pages 반영 1~3분).
- 최근 해시: g1-9-class/index.html = b77287c6adbb, links/fbi/index.html = 35f0c6564eb2 (이후 바뀌었을 수 있으니 수정 전 재확인)
- 삭제는 사용자가 명시적으로 요청했을 때만.

## 4. 사용자 규칙 (수업용 앱 중심)
- 앱 화면에 이모지 금지, 간결하고 신뢰 가는 형식. "검수 전" 같은 문구 금지(에이전트 검수를 다시 돌려 오류를 고친 뒤 제거).
- 수업용 화면에 조작법·사용 안내 문구를 넣지 않는다. 사용법은 별도 데모/PDF로.
- 한 줄 정리·마무리 문구는 명사형으로 끝낸다(예: "...원래 수준으로 돌아옴"). "~입니다/~하세요", "~한다는 얘기" 금지. 마무리 글씨는 너무 크지 않게.
- 영어가 나오면 항상 괄호로 한글 해석 병기. 학생이 문제를 풀기 전 화면에는 한글 해석을 넣지 않는다(해설에서만).
- 하이라이트: 문장 전체가 아니라 핵심 어휘·청크 단위. 내용 핵심=노랑, 순서·삽입 단서=굵은 밑줄(역접 빨강, 순접·지시사·예시 초록), 단서 말풍선=핑크.
- 수업 화면 마무리는 전자칠판 한 화면(스크롤 없음). "컨닝페이퍼" 표현 금지, 그냥 "단어".
- 작업 순서는 항상 23년 -> 24년 -> 25년.
- 학생은 당분간 1쇄 책으로 푼다. 2쇄 기준 변경은 필요할 때 반영하고, 학생이 책에서 푼 답을 틀렸다고 처리하지 않는다.
- 동료 선생님께는 html 파일이 아니라 링크로 전달.
