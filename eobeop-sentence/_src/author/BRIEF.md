# 어법 제대로 "문장분석" 챕터 데이터 작성 브리프 (에이전트 공통)

## 무엇을 만드나
해커스 어법 제대로 CH.NN의 POINT 쪽 문장(예제 + 교재 연습문제)을 한 문장씩 "문장분석" 카드로 만든다.
학생용 앱(문장을 덩어리로 끊고 → 핵심 덩어리 누르기 → 정답 고르기 → 분석 확인)과 인쇄용 PDF가 이 데이터 하나로 자동 생성된다.
너가 쓰는 것은 **author/chNN.py 한 파일**(덩어리 끊기·한글 직독직해·성분 표시·정답 쌍·정리 노트)뿐이다.
해석(tr)·해설(why)·함께 알아둘 것(ex)·구조 칩(st)은 원본(src/data_chNN_points.py)에서 **자동으로 복사**되므로 건드리지 않는다.

## author/chNN.py 형식
```python
# -*- coding: utf-8 -*-
META = {   # POINT 번호 k 마다 하나
 1: dict(sub='POINT 제목(짧게)', prompt='첫 번째 누르기 안내(한 줄)',
         taps=[dict(k='C', t='시간 표현을 누르세요')],      # 누르기 단계. k는 S/M/C 중 이 POINT의 핵심 종류. 여러 단계 가능([S단계, M단계])
         cprompt='맞는 말을 고르세요',                        # 정답 고르기 안내(생략하면 '맞는 말을 고르세요')
         pnote=('POINT 노트 제목','규칙 한 줄','규칙 한 줄')),   # 교재 POINT 옆에 쓸 정리: 제목 + 1~3줄
}
def C(en,ko,k='',lab='',h=None): return (en,ko,k,lab,h)
ITEMS = {  # (POINT번호,'예제' 또는 '번호문자열') 마다 하나. show.py에 나온 모든 항목을 빠짐없이.
 (1,'예제'): dict(c=[C('Lilian Bland','Lilian Bland는','S','S 주어'), C('became','되었다','V','V became (has become 아님)'), ...],
                  v=('became','has become'),            # (정답, 오답) — 정답은 V 덩어리 안에 그대로 있어야 함
                  n=('노트 제목','줄1','줄2')),          # 문장 옆에 쓸 정리: 제목 + 1~3줄
}
```
C()의 인자: (영어 덩어리, 한글 직독직해, 종류, 라벨, h)
- 종류 k: 'S' 핵심 대상(원본 <S>) / 'M' 건너뛸 꾸밈말(원본 <M>) / 'V' 정답이 들어 있는 덩어리 / 'C' 단서·연결어(원본 <C>) / '' 일반
- 라벨: S·M·V·C 덩어리에는 반드시(짧게, 20자 이내). 예) 'S 복수', '전치사+명사구 수식어', 'V became (has become 아님)', 'C 과거 시간표현'. 일반('') 덩어리는 라벨 ''.
- h: 한 덩어리 안에서 일부만 색칠할 때 [('who','c'),('runs','v')] (c주황/s파랑/v초록, 덩어리 안에 순서대로 나오는 부분문자열). 단서가 정답 덩어리 안에 같이 있을 때 쓴다(예: 'who runs ...' / 'Rarely does'). h를 쓰면 그 덩어리의 통색칠이 꺼지고 h 부분만 색칠된다.

## 가장 중요한 규칙 (자동검수가 확인 + 눈검수 대상)
1. 덩어리 영어를 순서대로 이어 붙이면 **정답으로 고친 문장 전체**와 정확히 같아야 한다(공백·대소문자·구두점 포함, 문장 끝 마침표도 마지막 덩어리에). [a|b]는 정답 쪽, {{x}}는 고친 말 쪽(맞는 문장 'O'면 x 그대로). show.py의 ans 참고.
2. 한글 직독직해: 영어 n번째 덩어리 ↔ 한글 n번째 덩어리가 순서대로 대응. 영어 동사가 있는 덩어리의 한글에는 동사까지 같은 덩어리에 넣는다. 영어 후치수식(분사·관계절·전치사구·to부정사)은 새 문장으로 풀지 말고 관형형으로(예: playing in the street → 거리에서 놀고 있는). 한글 덩어리에 영어 알파벳 금지(고유명사도 한글로 또는 원문 그대로 영어 덩어리에서만).
3. 덩어리는 한 호흡으로 묶는다: Today/However/In 1910 같은 1~2단어 부사어는 뒤 덩어리와 합치고(단, 단서 C로 눌러야 하면 따로), 짧은 전치사구는 앞 덩어리에 붙이고, 동사+짧은 목적어는 한 덩어리로 해도 된다. 한 덩어리가 너무 길면(영어 9단어 초과) 의미 단위로 끊는다. 한 문장 덩어리 수는 보통 3~7개.
4. 정답 덩어리(V)는 [a|b]/{{x}} 자리가 들어 있는 덩어리다. v=(정답,오답): 정답 문자열은 V 덩어리 영어 안에 그대로 있어야 한다(여러 단어 가능: 'have solved'). 오답은 원본 [a|b]의 다른 쪽 / {{x}}의 고치기 전 말 / 'O'(맞는 문장)이면 학생이 헷갈릴 만한 틀린 형태(원본 why 참고). 원본 ans에 'a/b'처럼 여러 개면 첫 번째.
5. 누르기 단계 taps: 이 POINT의 핵심을 학생이 먼저 눌러 찾게 한다(예: 시제 → 시간 단서 C, 수 일치 → 주어 S, 가정법 → if절/조건 C 등). 세트 안 **모든 문장에** 그 종류의 덩어리가 ≥1개 있어야 한다. 필요하면 S/M/C를 원본 태그 외에 직접 지정해도 되지만 원본 <S><M><C> 가 가리키는 말은 반드시 해당 종류 덩어리(또는 h)에 포함시킨다.
   - 안내문(t)은 한 줄, 해라체 아님: '~를 누르세요'.
6. 쉬운 말: 노트(n)·pnote는 초6 학생에게 짚어 주듯. 영어가 나오면 필요한 한글 뜻 병기. 이모지·특수 장식 금지. 학생이 읽는 글은 짧게(노트 줄은 40자 안팎).
7. 노트 n: 제목은 "무엇을 알아야 하는지" 한 구절(예: '시간 단서로 시제 고르기'), 줄1은 '핵심 덩어리 → 정답' 요약(영어 일부 + 화살표), 줄2는 이유 한 줄. pnote: 이 POINT의 규칙을 교재 POINT 옆에 쓸 수 있게 1~3줄.
8. 같은 POINT 안의 문장은 모두 같은 설계(같은 taps, 비슷한 라벨 문체)로 일관되게. 챕터 안 POINT끼리도 문체 통일.
9. 문장 하나하나 원본(show.py)의 영어·정답·해석과 맞는지 직접 눈으로 확인한다. 원본 해석(ko)과 너의 직독직해 뜻이 어긋나면 안 된다.
