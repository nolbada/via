# 구조분석(sx) 검수 지침 (검수자용)
BRIEF_SX.md 를 먼저 읽는다(태그·메모 규칙). 이제 out/chNN.json 을 처음 보는 눈으로 검수하고 직접 고친다(in/chNN.json 의 영어·해석·정답과 대조).
확인할 것(모든 문항 전수):
1. 모든 절의 동사가 {v}/{a}로 빠짐없이 표시됐는가(be동사·조동사 포함), 준동사 표지({p})가 맞는가(to부정사의 to, 동명사·분사 -ing/-ed). 동사가 아닌 말을 {v}로 단 곳은 없는가.
2. {c}가 접속사·관계사·의문사에만 달렸는가(전치사 like·as·than 구분: 접속사일 때만 {c}). 등위접속사 and/but/or 포함.
3. 【 】가 절·준동사구의 범위를 정확히 묶는가(시작·끝 위치).
4. 초록 메모의 문법 설명이 정확한가: 용법 분류(형용사적/부사적/명사적, 계속적/한정적), 수식 대상, 병렬 대상, 가주어/진주어 등. 틀렸거나 애매하면 고치거나 지운다.
5. {a}가 정답(ans)에 해당하는 말에 달렸는가. 한글 해석(tr)·덩어리 한글과 구조가 어긋나지 않는가.
6. 메모 40자 이하, 화살표·이모지 없음, 쉬운 말. 학생이 오해할 표현 금지.
고칠 때는 out/chNN.json 의 해당 항목만 수정(영어 글자 불변). 끝나면 `python3 mk_sx.py NN` errors=0 확인. 보고: 검수 문항 수, 고친 문항 수와 대표 유형 2~3개 (3줄 이내).
