명령문, 감탄문

  1. STEP 1알맞은 말 고르기
  2. STEP 2명령문 완성
  3. STEP 3감탄문 전환
  4. STEP 4영작
POINT 1

명령문

동사원형 ~~해라
Don’t[Do not] + 동사원형 ~~하지 마라

보통 주어(you)를 생략
please는 앞이나 뒤에 붙이면 공손한 표현

POINT 2

Let’s 제안

Let’s + 동사원형 ~(우리) ~하자
Let’s not + 동사원형 ~(우리) ~하지 말자

권유·제안할 때 사용

POINT 3

What 감탄문

What (+ a/an) + 형용사 + 명사 (+ 주어 + 동사)!정말 ~한 …구나

명사가 복수형이거나 셀 수 없는 명사면 a/an을 쓰지 않음

POINT 4

How 감탄문

How + 형용사/부사 (+ 주어 + 동사)!정말 ~하구나
How 의문문How + 형용사 + 동사 + 주어?

감탄문은 주어 + 동사 순서이고 끝에 !를 씀

STEP 1

( ) 안에서 알맞은 말을 고르시오

  • ① 문장이 명령문인지, 제안(Let’s)인지, 감탄문인지 구분한다.
  • ② 명령문은 동사원형, 금지는 Don’t, 제안의 부정은 Let’s not을 떠올린다.
  • ③ 감탄문은 형용사 뒤에 명사가 있으면 what, 없으면 how를 고른다.
STEP 1 · 1번

(What / How) beautiful the sky is!

단어 뜻
  • beautiful(아름다운)
  • the(그)
  • sky(하늘)
  • is(be동사 ‘~이다’ 현재형)
  • what(무엇; 감탄문에서는 ‘정말 ~한 …구나’)
  • how(어떻게; 감탄문에서는 ‘정말 ~하구나’)
생각해 보기
  • beautiful(아름다운) 뒤에 명사가 있나요, 없나요?
  • 본책 p.170 B 감탄문의 what 감탄문과 how 감탄문 틀을 비교해 보세요.

STEP 2

( ) 안의 말을 이용하여 명령문을 완성하시오 (Let’s는 사용하지 말 것)

  • ① 긍정 명령문인지 부정 명령문인지 상황에서 판단한다.
  • ② 긍정은 동사원형, 부정은 Don’t + 동사원형으로 쓴다.
  • ③ please가 있으면 명령문 앞(또는 뒤)에 붙인다.

  • careful(조심하는)
  • is(be동사 ‘~이다’ 현재형)
  • the(그)
생각해 보기
  • 바닥이 젖었으니 상대에게 무엇을 하라고 말하는 문장인가요?
  • 명령문은 어떤 동사 모양으로 시작하나요? be의 원형을 그대로 쓸지 생각해 보세요.

STEP 3

다음 문장을 감탄문으로 바꿔 쓰시오 (주어와 동사는 생략하지 말 것)

  • ① very, really를 빼고 형용사와 명사를 찾는다.
  • ② 명사가 있으면 What 틀, 없으면 How 틀에 넣는다.
  • ③ 마지막에 주어와 동사를 그대로 붙이고 !를 쓴다.

STEP 4

우리말과 일치하도록 ( ) 안의 말을 이용하여 문장을 완성하시오

  • ② 알맞은 틀(Don’t / Let’s / What)에 주어진 말을 넣는다.
  • ③ 빈칸 수에 맞는지 확인한다.
